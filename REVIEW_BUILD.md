# Review versions

The current Meda app is version 0.2: real accounts, server-side records/media, and a working provider workflow. Run it using the instructions in README.md. It requires the Node API; a single offline HTML file cannot provide these capabilities.

The earlier single-file visual demo remains at `prototype/Meda-offline-review.html` and the original `Meda-review.html` workspace download. That version uses temporary in-memory demo data and has no authentication or durable storage. It is preserved for reference and is not the current product.

See `VALIDATION.md` for what was tested, `DEVELOPMENT.md` for developer details, and `infra/aws/AWS_DEMO.md` for the prepared AWS hosting steps. There is no live hosted URL until an authorized AWS deployment and its readiness checks are completed.
